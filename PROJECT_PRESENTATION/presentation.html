System Design

Dual-Engine Decoupled Architecture

Client-Tier Decoupling (Facade Pattern)

UI components never call raw SQL or endpoints directly. All data access flows through our Service Facade Layer (dealService, contactService), which automatically routes to Live Supabase or Local Fallback.

Live Cloud Mode (Online)

Client SDK transmits requests over HTTPS with Bearer JWT tokens. PostgreSQL evaluates Row Level Security (RLS) directly on the database engine to enforce role access.

Local Storage Mode (Resilience)

If internet drops during a presentation, localCrmStorage steps in transparently. Full CRUD, role switches, and pipeline drag-and-drop operate with zero exceptions.

Database Engineering

PostgreSQL Schema & Security

Relational Schema

  • 5 Relational Tables: user_profiles, contacts, deals, activities, tasks.
  • 6 Custom ENUMs: Enforcing data type integrity at the SQL engine level.
  • 17 B-Tree Indexes: Fast lookups across stages, emails, and foreign keys.
  • SQL Triggers: on_auth_user_created auto-generates profiles on signup.

Row Level Security (RLS)

  • Security enforced directly inside PostgreSQL, not vulnerable client-side code.
  • is_admin() & is_manager_or_above() SQL helper functions.
  • Sales Reps are strictly constrained to user_id = auth.uid().
  • Managers gain automatic cross-team pipeline visibility.
